## Conversion notes

Temporary copies were used to remove empty paragraphs and convert floating images to inline layout, avoiding blank pages and image/text overlap. Report text was preserved. Animated images appear as still frames in PDFs; use the MP4 assets for motion.

The reports are included in the No Rail document catalog and the collapsible Development Reports collection. Selected images support the existing technical breakdowns. Nothing was pushed or published.
