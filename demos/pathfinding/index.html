Pathfinding

A browser build of my original openFrameworks C++ project. Compare Dijkstra and A* on small and large graphs, or guide an agent through an editable navigation grid.

Graphs: select start and goal nodes, then Run Search; without a selection the search uses random endpoints. Navigation Grid: click a destination to move the agent. Toggle Wall Building to paint obstacles, then switch it off to navigate. Algorithm and heuristic controls apply to graph mode; grid navigation uses A* with Euclidean distance.
